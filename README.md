# Sistema de Cifrado y Descifrado (C y Python)

Herramienta de consola desarrollada como proyecto académico para la asignatura de Arquitectura de Computadoras. El sistema implementa algoritmos de sustitución lógica para encriptar y desencriptar cadenas de texto mediante dos métodos distintos.

## 🚀 Tecnologías y Lenguajes
* Lenguaje C
* Python

## ⚙️ Métodos de Cifrado
El sistema cuenta con un menú interactivo que permite elegir entre las siguientes opciones:
1. **Abecedario Desordenado:** Sustitución de caracteres mapeando el abecedario normal con una versión desordenada predefinida (`qwertyuiopasdfghjklzxcvbnm`).
2. **Vocales Invertidas:** Reemplazo directo de las vocales tradicionales por su contraparte en posición invertida (`uoiea`).

## 🧠 Lógica y Estructura
* **Versión en C:** Optimizada mediante el uso de punteros, matrices y la librería `<string.h>` para la manipulación eficiente de memoria y caracteres.
* **Versión en Python:** Implementación adaptada a las bondades del lenguaje utilizando métodos nativos de cadenas (como `.find()`) y estructuras de control dinámicas (match-case).
